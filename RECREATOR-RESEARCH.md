# Research, missing capabilities and adoption decisions

Reviewed 2026-11-06. This is a scoped engineering synthesis of primary sources and the existing catalog, not a claim to have reproduced every paper or installed every tool. The executable core is deliberately small; optional services require their own version, license, dependency, access and runtime checks.

The [machine-readable research index](references/recreator-research-index.json) records twelve core sources with exact review scope and untested external-runtime status. Additional optional tool links below are discovery/adoption references, not installation claims.

## What closes which gap

REA contributes coordinated exploration and reverse-engineering workflows. Ghidra contributes binary analysis where an authorized artifact is available. Neither tool by itself supplies server source, training data, hidden configuration, provider relationships, production operation, independent acceptance or complete product discovery. ## Lessons from the primary research

Reflexion describes feedback stored in episodic text memory without updating model weights. This supports a distinction between reusable procedures and training. The suite implements scoped procedure storage and review gates; it does not reproduce the paper's evaluation. Voyager's skill-library work concerns an embodied Minecraft setting. Treat applying that pattern to enterprise product reconstruction as a design inference requiring its own target benchmark. [Reflexion](https://arxiv.org/abs/2303.11366), [Voyager](https://arxiv.org/abs/2305.16291).

LongMemEval evaluates several memory abilities, including updates and abstention. Our adoption is to test stale-fact replacement, scope boundaries, contradictory observations and refusal to infer unsupported facts. AgentPoison studies poisoned agent memory and knowledge bases; our adoption is to treat retrieved procedures as untrusted data with provenance and promotion review. Neither paper establishes that these controls eliminate all memory failures. [LongMemEval](https://arxiv.org/abs/2410.10813), [AgentPoison](https://arxiv.org/abs/2407.12784).

LangGraph separates graph checkpoints from cross-thread stores. Temporal models service interactions as Activities and documents idempotency considerations. Our architectural choice is to separate task recovery, reusable knowledge and external side effects. A retryable scheduler cannot by itself prove exactly-once external execution. [LangGraph](https://docs.langchain.com/oss/python/langgraph/persistence), [Temporal](https://docs.temporal.io/activities).

## Production architecture and explicit extension points

The shipped core is a single-writer reference controller, artifact store, check runner, repair transaction manager, hypothesis ledger, scoped lesson registry and agent handoff. It is not an autonomous model service or enterprise orchestration backend. An agent supplies reasoning, research and candidate code using the ordinary workflow; deterministic code controls the recorded checks and bounded local repair.

For hosted operation use: authenticated control API; hosted PostgreSQL for versioned task state and row-level tenant separation; encrypted object storage for raw evidence; durable scheduler; ephemeral workers; secret broker; restricted egress; provider sandbox adapters; independent verification workers; trace/metric export; deployment reconciler. Choose one scheduler and one persistence authority. Avoid two partially authoritative stores that can silently diverge.

Task states should include discovered, scoped, awaiting-access, researching, experiment-ready, executing, verifying, review-required, accepted, rejected, cancelled and blocked. Each transition needs a task ID, current version, lease/owner, action ID, input/output digests, policy decision, budget reservation, timeout, retry ceiling and completion evidence. The current CLI records local runs and repair events; distributed task leases and this hosted API are extension requirements, not implemented features.

Use idempotent external operation keys and a transactional outbox; acknowledge an external action only after a durable result or a reconciled provider receipt. If a timeout leaves the outcome uncertain, reconcile before retrying. Keep capture, reference account, candidate and evaluator identities separate. Restrict workers to the resources each task requires. No arbitrary shell, production secret inheritance, self-granted permissions or unreviewed plugin installation.

Before adopting an optional repository: pin a reviewed release/commit, inspect license and maintenance, inventory dependencies, evaluate permissions, run a minimal owned fixture, retain its actual output, test failure/recovery, and add only the missing adapter. A catalog link means discoverable, not installed or trusted. The existing index retains original source records; do not relabel all catalog entries as runtime-verified.

## Definition of a useful result

Coverage is a vector: known surfaces/states; observed behavior; experiment strength; contract compatibility; visual match; negative security checks; integration outcomes; durability; load; operational readiness. Show each dimension's denominator, tested scope and unknowns. A single inflated percentage hides missing domains. Unseen features remain discovery risk; private training data, unavailable providers, proprietary services and internal deployment details may remain inaccessible. The framework narrows uncertainty through evidence; it cannot make absent information certain.
